# Licences

Licence texts for parts of the built app whose sources don't ship one where the build can find it. `Scripts/notices.py` puts them, with every other bundled part's own licence, into the app's acknowledgements.

- `LGPL-2.1.txt`, `LGPL-3.0.txt`: from gnu.org, for GLib, JSON-GLib, libintl and Lensfun
- `Lensfun-database.txt`: the lens database's CC BY-SA 3.0 notice
- `Restormer.txt`: Restormer's MIT licence, for the Rescue Focus models
